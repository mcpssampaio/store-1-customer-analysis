# 🛒 Store 1 - Análise de Dados de Clientes

Este projeto foi desenvolvido no âmbito do bootcamp da **TripleTen** para analisar o comportamento dos clientes de uma plataforma de comércio eletrónico (*Store 1*).

## 🚀 Tecnologias Utilizadas
- **Python** (Pandas, Try-Except, Loops, Estruturas de Dados)
- **Jupyter Notebook**

## 🎯 Objetivos do Projeto
- Avaliar a qualidade de uma amostra de dados recolhidos.
- Limpar e tratar dados em falta (`NaN`) e valores incorretos.
- Calcular métricas de gastos por categoria de produtos (total, mínimo e máximo).
- Utilizar ciclos (`while`, `for`) e estruturas condicionais para segmentar clientes por critérios de fidelização e idade.

## 💡 Principais Aprendizagens
Este projeto permitiu consolidar competências fundamentais de tratamento e pré-processamento de dados em Python, garantindo bases limpas e estruturadas para a tomada de decisões de negócio.
